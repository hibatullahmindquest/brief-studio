# Contributing to PostForge AI

Thanks for your interest in contributing.

## Quick start

1. Fork this repository.
2. Create your branch from `master`.
3. Install dependencies:
   - `npm install`
4. Create `.env.local` (you can copy from `.env.example`).
5. Run local checks:
   - `npm run lint`
   - `npm run build`
6. Start local dev server:
   - `npm run dev`

## Branch naming

Use clear branch names, for example:

- `feat/content-lab-improvements`
- `fix/login-error-handling`
- `docs/readme-quickstart`

## Pull request checklist

- Keep changes focused and small.
- Explain what changed and why.
- Include screenshots for UI changes.
- Confirm `npm run lint` and `npm run build` pass.
- Link related issue (if any).

## Good first contributions

- Improve UI copy and onboarding hints
- Add tests for auth and API routes
- Improve accessibility and keyboard navigation
- Improve docs and setup guides

## Reporting bugs

Please use the bug issue template and include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Browser/OS and screenshots
